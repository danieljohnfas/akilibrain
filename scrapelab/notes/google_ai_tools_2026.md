# 5 Google AI Tools (July 2026)

*Source: Nick's promotional breakdown from July 25, 2026*

This document outlines 5 recently highlighted Google AI tools and how they can be applied to the other projects in `C:\Users\nnm\Documents\projects`.

## 1. Pomelli (AI Marketing Tool)
**What it is:** Analyzes a website link (brand colors, fonts, tone) to generate full social media content (posts, captions, visuals) that matches the brand automatically.
**How to use it on your projects:**
- **Vault:** Feed it the URL of the site to automatically generate matching promotional posts for Twitter or Reddit, driving traffic with perfectly themed dark/vibrant aesthetics.
- **Photosplit:** Generate visual-heavy social media content demonstrating the cropping, resizing, and converting tools to attract users to the utility site.
- **Akilihub:** Create consistent, professional branding posts for this Next.js app to build a user base.

## 2. Stitch (AI UI Design Generator)
**What it is:** Generates modern app/website designs from a text prompt and exports directly to code (HTML/CSS/JS/React).
**How to use it on your projects:**
- **Photosplit:** Use it to redesign UIs for tools like `crop.html`, `resize.html`, or `convert.html` with sleek, modern elements (e.g., glassmorphism, smooth animations) and export directly to HTML/CSS.
- **Akilihub:** Since Akilihub uses Next.js and Tailwind/CSS, Stitch can generate and export complete React components for new features instantly.
- **Vault:** Overhaul older pages like `alternatives.html` or `contact.html` with a fresh, modern aesthetic.

## 3. Google Opal (No-Code AI Workflow Builder)
**What it is:** Google's version of n8n or Make.com. Describe workflows in plain English (e.g., "pull data from Sheets and send an email"), and Opal builds it using AI.
**How to use it on your projects:**
- **Firecrawl:** Integrate Firecrawl's powerful scraping API into an Opal workflow (e.g., scrape competitor data -> summarize with LLM -> save to Google Sheets -> send email report).
- **Holy:** Replace the manual `scrape_escorts.py` with a fully automated, cloud-hosted workflow that pulls data periodically and drops it into a database or spreadsheet without maintaining Python scripts.
- **Akilihub:** Create background automation workflows, such as sending welcome emails or processing scheduled database cleanups, without writing backend code.

## 4. Antigravity (AI Code Editor)
**What it is:** An AI coding environment built for "vibe coding". You prompt what you want built, and it writes the code. Integrates with Stitch.
**How to use it on your projects:**
- **Partner:** Use Antigravity to build and debug complex agent interactions within the orchestrator.
- **All Projects:** Serve as the primary IDE for all projects. You can generate UIs in Stitch, bring them into Antigravity, and seamlessly wire up the backend logic for `akilihub` (Next.js) or Cloudflare workers in `vault`.

## 5. Mixboard (AI Image Remixer)
**What it is:** A Canva + Pinterest hybrid. Generate multiple AI images and mix/combine elements across them until you get the exact visual you want.
**How to use it on your projects:**
- **Vault:** Generate and remix custom banners, thumbnails, or promotional content that fits the site's unique aesthetic.
- **Photosplit:** Create beautiful sample images, placeholder assets, or hero graphics for the landing page (`index.html`) to demonstrate the tool's capabilities.
- **Akilihub:** Design unique logos, hero sections, and UI assets that can't be easily found on generic stock photo sites.
